# tui-template — mock-сервис (Rust + ratatui)

Минимальный рабочий шаблон TUI, демонстрирующий принципы из [`../principles.md`](../principles.md)
и [`../workflow.md`](../workflow.md). Mock-«монитор сервисов»: список сервисов со
статусами и метриками, панель деталей, статус-бар, справка.

## Запуск

```bash
cargo run
```

## Структура

| Файл | Что |
|---|---|
| `src/theme.rs` | палитра + семантические роли (`accent`/`success`/`border`/…) |
| `src/model.rs` | чистое состояние (сервисы, метрики, история CPU, логи, тост, тик) — без UI-типов |
| `src/ui.rs` | отрисовка: вкладки, список, gauge + sparkline, логи, статус-бар, оверлеи |
| `src/main.rs` | event loop: ввод + тик + draw |

## Что демонстрирует (виджеты ratatui)

- **`Tabs`** — вкладки Overview/Logs (переключение `Tab`).
- **`Gauge`** — индикаторы CPU/MEM выбранного сервиса (прогресс-бары `█`).
- **`Sparkline`** — мини-график истории CPU (`▁▂▃▄▅▆▇`).
- **`List`** — список сервисов (с бейджами) и панель логов.
- **`Paragraph` + `Block`** — панели с рамками, статус-бар, тост, оверлей справки.

## Как это соотносится с принципами

- **Список + статус-бар + действия** — сервис = список; `j/k` выбор, `Enter`
  toggle, `r`/`s`/`S` действия; статус-бар показывает `N/total up`.
- **Master-detail + вкладки** — слева список, справа детали (Overview с
  графиками / Logs).
- **Семантические роли** — цвет только через `Theme` (`theme.success()` и т.п.),
  палитра `DARK`/`LIGHT`.
- **Бейджи состояния** — ` RUNNING `/` STOPPED `/` RESTART ` цветными «пилюлями».
- **Оверлеи** — справка `?` центрирована; тост справа сверху.
- **Живой фидбек** — `tick()` обновляет метрики/историю CPU/логи без блокировки
  (poll с таймаутом).
- **Крайние случаи** — фокус панелей `h`/`l`, `Tab` для вкладок, `Esc`/`q`
  выход, `Ctrl+C`.

## Как сделать из этого свой инструмент

1. Скопируй папку `template/`.
2. Замени `seed()` в `model.rs` на реальный источник данных.
3. Подмени действия в `handle_key` (main.rs) на реальные вызовы.
4. При необходимости переименуй пакет в `Cargo.toml`.
