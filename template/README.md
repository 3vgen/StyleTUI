# tui-template — mock-сервис (Rust + ratatui)

Минимальный, но богатый рабочий шаблон TUI, демонстрирующий принципы из
[`../principles.md`](../principles.md) и возможности ratatui: mock-«монитор
сервисов» с несколькими панелями, вкладками и разными виджетами.

## Запуск

```bash
cargo run
```

## Структура

| Файл | Что |
|---|---|
| `src/theme.rs` | палитра + семантические роли (`accent`/`success`/`border`/…) |
| `src/model.rs` | чистое состояние (сервисы, метрики, история CPU, логи, тост, тик) — без UI-типов |
| `src/ui.rs` | отрисовка: заголовок, вкладки, 3 колонки, графики, логи, статус-бар |
| `src/main.rs` | event loop: ввод + тик + draw |

## Какие виджеты ratatui демонстрирует

| Виджет | Где | Зачем |
|---|---|---|
| `Paragraph` + `Block` | заголовок, панели, статус-бар | рамки, заголовки, тост |
| `Tabs` | вкладки `Dashboard / Metrics / Logs` | переключение видов (`Tab`) |
| `List` + `ListState` | список сервисов, логи | выбор/навигация `j`/`k` |
| `Gauge` | CPU / MEM в Details | прогресс-бары |
| `Sparkline` | история CPU | мини-график `▁▂▃▄▅▆▇` |
| `BarChart` | колонка «CPU %» | столбики по сервисам |
| `Chart` + `Dataset` + `Axis` | вкладка Metrics | линейный график (braille) |

## Клавиши

`j`/`k` — выбор · `gg`/`G` — края · `h`/`l` — фокус · `Tab` — вкладка ·
`Enter`/`r`/`s`/`S` — toggle/restart/stop/start · `?` — справка · `q` — выход.

## Как это соотносится с принципами

- **Список + статус-бар + действия** — сервис = список; статус-бар показывает `N/total up`.
- **Master-detail + несколько панелей** — слева список, по центру детали,
  справа агрегат (бар-чарт), снизу логи.
- **Семантические роли** — цвет только через `Theme` (`theme.success()` и т.п.),
  палитра `DARK`/`LIGHT`.
- **Бейджи состояния** — ` RUNNING `/` STOPPED `/` RESTART ` цветными «пилюлями».
- **Оверлеи** — справка `?` центрирована; тост справа сверху.
- **Живой фидбек** — `tick()` обновляет метрики/историю/логи без блокировки
  (poll с таймаутом).
- **Крайние случаи** — фокус панелей `h`/`l`, вкладки `Tab`, `Esc`/`q` выход.

## Как сделать из этого свой инструмент

1. Скопируй папку `template/`.
2. Замени `seed()` в `model.rs` на реальный источник данных.
3. Подмени действия в `handle_key` (main.rs) на реальные вызовы.
4. При необходимости переименуй пакет в `Cargo.toml`.
