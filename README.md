# StyleTUI — принципы дизайна TUI

Общий (framework-agnostic) справочник по дизайну терминальных интерфейсов.
Цель: чтобы агент, прочитав эти заметки, мог спроектировать и написать TUI под
**любую конкретную задачу** — не привязываясь к конкретному приложению.

Референс-реализация этих принципов — TUI `kvn` (Rust/ratatui), описанная в
[reference-kvn.md](reference-kvn.md) как **пример применения**, а не как предмет
изучения.

## Содержание

- [principles.md](principles.md) — общие принципы: раскладка, цвет/темы, виджеты,
  взаимодействие, видимость состояния, производительность, устойчивость.
- [workflow.md](workflow.md) — пошаговый процесс «задача → дизайн TUI» + разобранный пример.
- [reference-kvn.md](reference-kvn.md) — kvn как конкретный пример этих принципов.

## Идея в одном абзаце

Хороший TUI — это **«список + статус-бар + действия»**:

- главная сущность задачи показывается как **список** в основной области;
- глобальное состояние — **однострочный статус-бар** (виден всегда);
- действия — **клавиши** (vim-стиль) + экран справки;
- настройки и подтверждения — **центрированные модалки**;
- вторичная информация — **панель деталей / логов / тост**.

Интерфейс **клавишный, минималистичный, с мгновенным фидбеком**; цвета задаются
**семантическими ролями** (акцент/ошибка/успех/граница), а не буквальными
значениями.

## Быстрый старт (что прочитать первым)

1. `workflow.md` — с него: как из описания задачи вывести структуру TUI (главные вопросы и шаги).
2. `principles.md` — «словарь» приёмов, к которому возвращаешься при выборе раскладки/цветов/клавиш.
3. `reference-kvn.md` — посмотреть, как всё это собрано в реальном приложении.

## Схема раскладки (общий случай)

```
┌─ (опционально) верхняя панель: метрики/заголовок ─────────────────┐
├──────────────────────────────────┬────────────────────────────────┤
│ Список (основная сущность)       │ Детали выбранного / логи       │
│  ├ строка                        │                                │
│  ├ строка (выбрана)              │                                │
│  └ строка                        │                                │
├──────────────────────────────────┴────────────────────────────────┤
│ СОСТОЯНИЕ  имя-активного           бейджи настроек/состояния      │
└───────────────────────────────────────────────────────────────────┘
   (сверху-справа поверх всего — тост; по центру — модалки)
```
