# kvn TUI — стиль и дизайн

Справочник по дизайн-системе TUI `kvn` (Rust, ratatui + crossterm, проект
`~/kvn`). Описывает принципы, раскладку, цветовую систему и взаимодействия,
чтобы переносить этот стиль в будущие проекты.

## Содержание

- [design-system.md](design-system.md) — раскладка, цвета/темы, виджеты, типографика, отступы.
- [interactions.md](interactions.md) — навигация, клавиши, оверлеи, модель фокуса.

## Коротко о стиле (суть)

kvn — **клавишный, минималистичный, терминал-нативный** интерфейс в духе
классических TUI-утилит (vim/lazygit/k9s):

- **Три горизонтальные зоны**: сверху панель трафика (только при активном VPN),
  посередине два вертикальных панели (Profiles | Logs), снизу однострочный
  статус-бар.
- **Всё от палитры**: ни один виджет не хардкодит цвет — любой стиль выводится
  из семантической `Palette` (акцент/ошибка/успех/граница/выбор). 22 встроенные
  темы + фолбэк.
- **Семантические роли, а не буквальные цвета**: `accent`, `error`, `success`,
  `warning`, `muted`, `border`, `selected` — виджеты обращаются к ролям, а тема
  решает, какие это RGB.
- **Vim-навигация**: `j`/`k`, `gg`/`G`, `h`/`l` (или стрелки) — переключение
  панелей, `?` — справка, `q`/`Esc` — выход из оверлея/приложения.
- **Бейджи состояния**: статус подключения (`CONNECTED`/`CONNECTING`/
  `DISCONNECTED`) и настройки (`KS`, `Auto`, DNS, режим роутинга) — компактные
  цветные метки в статус-баре.
- **Оверлеи как центрированные модалки**, тосты как временные уведомления
  справа сверху.
- **Фиксированная ширина колонок + приоритетное обрезание** — выравнивание
  таблиц и статус-бара не разваливается на узких терминалах.

## Что описывается подробнее

| Файл | Что внутри |
|---|---|
| `design-system.md` | точная раскладка и констрейнты, палитра/темы (формат `themes/*.toml`), таблица семантических стилей, виджеты (StatusBar, Toast, строки профилей, панель трафика), правила отступов/выравнивания |
| `interactions.md` | полная карта клавиш, модель фокуса панелей, оверлеи и их поведение, тосты, пороги минимального размера терминала |

## Источники (код kvn)

- `src/ui/styles.rs` — `Theme`: семантические стили над `Palette`.
- `src/ui/palette.rs` — `Palette`, `mix()`, `to_rgb()`, загрузка тем.
- `src/ui/widgets.rs` — `StatusBar`, `Toast`, форматирование величин.
- `src/ui/layout.rs` — раскладка, панели, строки профилей, оверлеи.
- `src/ui/help.rs` — справка по клавишам.
- `themes/*.toml` — 22 палитры (Omarchy 4).
